## 1. System Executive Overview

The **Nigeria Immigration Service Personnel Posting Management System (NIS-PPMS)** is an enterprise web platform designed to streamline, track, analyze, and manage the deployment of NIS officers across all Zonal Commands, State Commands, Border Posts, Control Posts, and Service Headquarters.

### Core System Features
* **Extensionless Clean URLs**: High-security, standard web navigation without `.php` file exposure (e.g. `/dashboard`, `/search`, `/analytics`).
* **Cryptographic IDOR Protection**: Cryptographic HMAC-SHA256 tokens bound to user sessions to prevent unauthorized address bar query tampering.
* **Intelligent Over-Stay Recommendation Engine**: Automated tracking of officers who have served in a formation for **over 5 years**, recommending priority re-postings.
* **Classified Reporting**: Print-ready officer histories featuring the official NIS Coat of Arms crest, semi-transparent `"CLASSIFIED"` background watermark, and generating user metadata.
* **Offline PWA Architecture**: Progressive Web App capabilities via Service Workers (`sw.js`) allowing cached officer search and viewing even when network connectivity drops.

## 2. User Roles & Access Control (RBAC)

The application operates on a strict **Role-Based Access Control (RBAC)** architecture. System permissions adapt dynamically based on the logged-in user's assigned role:

| Role Name | Scope & Operational Permissions | Key Restricted Actions |
| :--- | :--- | :--- |
| **Super Admin** | Full global access to all system modules, user accounts, audit logs, formation creation, and officer deletions. | None |
| **Admin** | System configuration, personnel roster updates, user creation, zone assignments, and posting reports. | Cannot modify Super Admin accounts. |
| **Service HQ** | Headquarters operational oversight, bulk postings, national analytics, and officer management. | Cannot access raw system logs. |
| **Zone / Command** | Formations assigned specifically to their Zonal Command or State Command. | Restricted to assigned zone personnel. |
| **User** | Read-only search, officer profile view, analytics hub viewing, personal profile management. | **Strictly prohibited** from updating postings, deleting personnel, uploading post order docs, or bulk operations. |

## 3. Authentication & Account Security

### 3.1 Logging In
1. Navigate to `http://localhost/nisposting/login` (or domain equivalent).
2. Enter your assigned **Username** and **Password**.
3. If Two-Factor Authentication (2FA) is enabled on your account, enter the 6-digit verification code generated by your Authenticator app.
4. Upon validation, the system initiates your secure, encrypted session and redirects you to the `/dashboard`.

### 3.2 Security Protections & Token Validation
* **Direct URL Tampering Rejection**: Manipulating URL query strings (e.g., manually editing `/editp?serviceNo=1` to `/editp?serviceNo=35562`) triggers an immediate **`403 Forbidden: Security Violation`** notice.
* **Cryptographic HMAC Tokens**: Every valid edit link contains a session-bound HMAC-SHA256 token verifying that the link originated from an official search or roster table.

## 5. Posting Operations & Document Management

### 5.1 Single Officer Posting Update (`/editp`)
1. From the Officer Search result, click **Update Posting** (visible only to Admin, Super Admin, and Service HQ roles).
2. Fill in the required deployment fields:
   * **New Posting Location / Command** (Selected from official zone/formation list).
   * **Posting Date** (Defaults to current date).
   * **Posting Order Reference Number** (e.g., `NIS/HQ/PO/2026/042`).
   * **Posting Type** (Routine, Special Assignment, Promotion, Discipline, Compassionate).
3. Click **Submit & Update Posting**.

### 5.2 Uploading & Managing Post Order Documents
* **Location**: Located above the Update Posting form on `/editp`.
* **Uploading**: Select an official PDF or scanned image document (`.pdf`, `.jpg`, `.png` up to 5MB), enter a brief document title, and click **Upload Document**.
* **Viewing**: Click the document link to preview attached deployment orders.
* **Deleting**: Admins can click **Delete** (requires POST confirmation). *Note: The delete action is hidden for `User` role accounts.*

### 5.3 Multi-Channel Officer Notification (SMS & Email)
Whenever a new posting order is submitted and saved in the system:
* **Instant SMS Alert**: The system automatically dispatches an SMS message directly to the posted officer's registered phone number.
* **Official Email Notification**: An official email is automatically sent to the officer containing their Service Number, Full Name, New Command/Location, Effective Date, and Posting Order Reference Number.

### 5.4 Destination Command In-App Notification
* Simultaneously, the system generates an **In-App Notification** (`posting_notifications`) visible on the top header bell indicator for officers assigned to the **Destination Command / Zone**.
* Alerts command leadership in real-time that a new officer has been posted to their formation, enabling them to prepare for reception and duty assumption.

### 5.5 Automated 30-Day Non-Reporting Escalation Engine
* The system features an automated background cron engine (`cron/send_reminders.php` / Notification Engine) that monitors officer assumption-of-duty status.
* **1-Month Threshold**: If a posted officer **fails to report to their new command within 30 days (1 month)** of the effective posting date, the application automatically flags the officer.
* **Escalation to Originator**: The system automatically generates a high-priority **Non-Reporting Incident Escalation Alert** sent directly to the **Originator / Issuing Officer of the Posting Order** (Service HQ / Posting Board), informing them that the officer has not assumed duty at their assigned command for disciplinary follow-up.

### 5.6 Disciplinary & Sensitive Posting Guards
* **Strict Paramilitary Posting Guard**: Under Nigeria Immigration Service Regulations, **any officer undergoing active disciplinary action is strictly prohibited from receiving a new posting or command transfer**.
* **Monitored Disciplinary Statuses**:
  * `Under Query` (Posting Blocked ⚠️)
  * `Under Interdiction` (Posting Blocked ⛔)
  * `Under Suspension` (Posting Blocked 🚫)
  * `Pending Disciplinary Action` (Posting Blocked ⚖️)
  * `Dismissed` (Posting Blocked ❌)
* **Automatic Enforcement**: If an administrator attempts to post an officer with an active disciplinary status on `/editp` or `/bulk`, the application blocks the submission with an unmissable red alert: **`POSTING BLOCKED (Disciplinary Guard): Officer [ServiceNo] is currently UNDER DISCIPLINARY ACTION`**.

### 5.7 Disciplinary Board Sidebar Module (`/disciplinary`)
* **Role Access Restriction**: The Disciplinary Board sidebar menu item and management portal are visible and accessible **ONLY** to **`Super Admin`**, **`Admin`**, and **`Service HQ` (`SHQ`)** accounts.
* **Adding Personnel to Disciplinary List**:
  1. Click **Disciplinary Board** on the sidebar under Administration.
  2. Click **Add Officer to Disciplinary List**.
  3. Enter the officer's **Service Number**, select their active status (`Under Query`, `Under Interdiction`, `Under Suspension`, `Pending Disciplinary Action`, `Dismissed`), and enter the official Query Reference Number & case details.
  4. Click **Save Disciplinary Action**. The officer is immediately locked and **blocked from receiving any postings**.
* **Clearing & Restoring Personnel**:
  1. Locate the officer on the Active Disciplinary Cases table at `/disciplinary`.
  2. Click the green **Clear** button.
  3. Confirm the prompt to reset the officer's status back to **Clean**, restoring full posting eligibility.

## 6. Bulk Posting Workflow

For mass redeployments across formations, authorized officers can perform CSV bulk posting updates:

1. Navigate to `/bulk`.
2. Download the official CSV Template (`serviceNo`, `new_location`, `posting_date`, `posting_order_ref`).
3. Upload the populated CSV file.
4. Review the **Preview & Conflict Check Table**.
5. Click **Confirm & Process Bulk Posting**.

## 8. Classified Report Generation & Printing

When generating official physical documentation for Service Files or Board Reviews:

1. Perform an officer lookup on `/search`.
2. Click **Print Record**.
3. The system generates a formatted, print-optimized document containing:
   * Centered **Nigeria Immigration Service Coat of Arms Crest** (`logo.png`).
   * Main Header: **NIGERIA IMMIGRATION SERVICE**.
   * Report Title: **Personnel Posting History/Report**.
   * Semi-transparent, 45-degree diagonal background watermark: **"CLASSIFIED"**.
   * Audit Metadata: **Generated on:** `[Timestamp]` | **Generated by:** `[Full Name of User]`.
